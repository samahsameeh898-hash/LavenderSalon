LAVENDER WOMEN'S SALON
=======================

Project structure:
- index.html              Main website page
- css/style.css           Design and responsive styling
- js/script.js            Small interactions
- assets/lavender_logo.png  Clean Lavender logo
- START_WEBSITE.cmd       Windows launcher

HOW TO RUN:
1. Extract the ZIP file.
2. Double-click START_WEBSITE.cmd.
3. The website will open at:
   http://localhost:8000

REQUIREMENT:
Python 3 must be installed on Windows.
The CMD file automatically tries "py" first, then "python".
